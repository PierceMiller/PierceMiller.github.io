# Selah — Bible Study v2

Selah is a static Bible-learning app hosted at /selah/ in the existing GitHub Pages repository.

## Learning model
The core loop is **Observe → Context → Interpret → Connect → Respond → Remember**.

The design intentionally makes the learner articulate observations and interpretations before revealing additional explanation. The final stage uses retrieval practice because research consistently finds retrieval improves long-term retention compared with repeated study.

Research:
- Roediger & Butler (2011): https://pubmed.ncbi.nlm.nih.gov/20951630/
- McDermott (2021): https://pubmed.ncbi.nlm.nih.gov/33006925/
- Larsen, Butler & Roediger (2009): https://pubmed.ncbi.nlm.nih.gov/19930508/

## Included
- Responsive dashboard
- Six-stage guided study engine
- Passage library
- Genre/context prompts
- Evidence-chain interpretation prompts
- Local study journal using browser storage
- Retrieval review queue
- Public-domain World English Bible sample passages
- No backend required
